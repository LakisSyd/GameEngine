# NPC Logic Studio — отладочная симуляция

1. Запусти Play (F5), освободи мышь (F2).
2. В Animation Tools включи NPC Logic Studio. Симуляция начнётся на паузе,
   появятся панели объектов и свойств, включатся NavMesh, пути и укрытия.
3. F2 переключает мышь интерфейса и свободный полёт: WASD, R/F вверх/вниз.
   Камера больше не привязана к мишени. F4 показывает состояния NPC.
4. Сними Pause simulation для непрерывной работы или нажимай Step 1/60 sec.
   Simulation speed меняет скорость от 0.1x до 2x только в студии;
   одиночный шаг остаётся равен 1/60 секунды.
5. Меняй Target XYZ: перемещается настоящая игровая сущность игрока вместе
   с физическим контроллером, а камера остаётся на месте. Управление игроком
   с клавиатуры отключено. Для теста выживания включи Target God Mode.
6. Выбирай NPC в списке объектов и изучай свойства. Для обновления навигации
   после изменения препятствий используй Rebuild navigation.
7. Exit Logic Studio возвращает обычную камеру и управление.

Save target A/B запоминает две позиции. Move target here переносит мишень
к выбранной закладке, не сбрасывая память NPC. Так удобно повторять выход
из-за стены. Закладки живут в текущем процессе, не записываются в сцену.
Это повтор положения мишени, а не детерминированный повтор всего боя.
В F4 строка Rejected разделяет отказы NavMesh, дистанции до напарника и
слишком близких/недавно посещённых точек. Счётчики относятся к последнему
подбору поисковой точки, а не ко всей истории симуляции.

Используются настоящие AI, физика, анимация и оружие, не отдельная модель боя.
Пауза останавливает также мировые часы. Шаг передаёт 1/60 секунды игровым
системам; физика сохраняет свой штатный механизм фиксированных шагов.

Ограничения первого варианта: это живая сцена, не изолированная копия с откатом.
Мишень — игрок, а не дополнительно созданный болванчик. Перемещение мишени
предусмотрено через Target XYZ, отдельного манипулятора пока нет. Не перемещай
мишень внутрь твёрдой стены: разрешение проникновения выполняет физика.
Не запускай одновременно Animation Studio с предпросмотром анимации: он
может подменить позу, которую ты пытаешься исследовать.

Если NPC стоит: F4 → Search failures и NavMesh status. Ноль найденных путей
не означает, что он обыскал сцену. Сначала проверь наличие сетки, положение
капсулы относительно поверхности и разрывы сетки у препятствий.
