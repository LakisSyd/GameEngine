# Справочник полезных алгоритмов

Этот раздел нужен не для заучивания. Перед новой механикой найди похожую задачу, выпиши входы и выходы, затем реализуй минимальный вариант и обязательно добавь визуальную проверку.

## 1 Безопасная нормализация

**Задача:** получить единичное направление без `NaN`.

**Вход:** произвольный вектор `v`.

**Выход:** единичный вектор и признак успеха.

```cpp
bool TryNormalize(const XMFLOAT3& value, XMFLOAT3& result)
{
    const XMVECTOR vector = XMLoadFloat3(&value);
    const float lengthSquared = XMVectorGetX(XMVector3LengthSq(vector));
    if (lengthSquared <= 0.000001f)
        return false;

    XMStoreFloat3(&result, XMVector3Normalize(vector));
    return true;
}
```

**Сложность:** O(1).

**Ловушка:** проверять длину уже после нормализации.

**Применение:** лучи зрения, движение, направление ствола, steering.

## 2 Квадрат расстояния

**Задача:** быстро сравнить кандидатов или радиус.

```cpp
float DistanceSquared(const XMFLOAT3& a, const XMFLOAT3& b)
{
    const float dx = a.x - b.x;
    const float dy = a.y - b.y;
    const float dz = a.z - b.z;
    return dx * dx + dy * dy + dz * dz;
}
```

Сравнивай с `radius * radius`. Квадратный корень нужен только для настоящего расстояния.

**Сложность:** O(1) на кандидата, O(n) для полного перебора.

## 3 Поле зрения через dot

**Вход:** нормализованный `forward`, направление к цели, полный угол FOV.

```cpp
const float halfFov = XMConvertToRadians(fovDegrees * 0.5f);
const float threshold = std::cos(halfFov);
const bool inside = Dot(forward, normalizedToTarget) >= threshold;
```

**Ловушка:** использовать полный угол вместо половинного.

**Применение:** дешёвый фильтр перед raycast. После dot всё равно проверяется препятствие.

## 4 Кратчайшая разница углов

```cpp
float ShortestAngle(float current, float target)
{
    return std::atan2(
        std::sin(target - current),
        std::cos(target - current));
}
```

**Выход:** значение от `-pi` до `pi`.

**Применение:** поворот NPC, турели, оценка ошибки прицеливания.

## 5 Луч и отрезок

Луч бесконечен при `t >= 0`. Для оружия и зрения обычно нужен отрезок с максимальным расстоянием.

```cpp
struct SegmentRay
{
    XMFLOAT3 origin{};
    XMFLOAT3 direction{}; // Единичный вектор.
    float maxDistance = 0.0f;
};
```

Создание из двух точек:

1. `delta = end - start`;
2. `distance = length(delta)`;
3. отклонить почти нулевую длину;
4. `direction = delta / distance`;
5. `maxDistance = distance`.

**Ловушка:** передать ненормализованное направление в функцию, которая считает `t` метрами.

## 6 Ray plane

**Формула:**

$$
t=\frac{(Q-O)\cdot N}{D\cdot N}
$$

**Порядок:** проверить параллельность, получить `t`, проверить диапазон, вычислить точку.

**Сложность:** O(1).

**Применение:** приказ на поверхность, маркер мыши, проекция тактической точки.

## 7 Ray sphere

**Порядок:** построить квадратное уравнение, проверить дискриминант, выбрать ближайший неотрицательный корень.

**Сложность:** O(1).

**Применение:** грубый broad phase, выбор персонажа, отладочные цели.

**Ловушка:** вернуть отрицательный корень, лежащий позади начала.

## 8 Ray AABB slab method

**Порядок:** для каждой оси найти интервал `t1..t2`, пересечь его с общим `tMin..tMax`, отклонить пустое пересечение.

**Сложность:** O(1), ровно три оси.

**Применение:** редактор, broad phase, грубая проверка видимости объекта.

**Ловушка:** делить на почти нулевую компоненту направления. Параллельная ось проверяется отдельно.

## 9 Lerp

$$
lerp(a,b,t)=a+(b-a)t
$$

**Применение:** цвет, позиция, числовой параметр.

**Ловушка:** использовать один и тот же `t` каждый кадр как будто это постоянная скорость. `current = lerp(current, target, 0.1)` зависит от FPS.

## 10 Экспоненциальное приближение

```cpp
const float alpha = 1.0f - std::exp(-speed * deltaTime);
current += (target - current) * alpha;
```

**Применение:** камера, плавный поворот, UI, шумные оценки AI.

**Плюс:** почти одинаковая реакция при разном FPS.

## 11 Fixed timestep

Физику удобно обновлять фиксированным шагом.

```cpp
accumulator += frameDelta;
while (accumulator >= fixedDelta)
{
    SimulateFixedStep(fixedDelta);
    accumulator -= fixedDelta;
}
```

**Ловушка:** бесконечно догонять после долгой паузы. Ограничивай `frameDelta` и число шагов.

**Применение:** физика, детерминированные таймеры, воспроизводимые тесты.

## 12 Cooldown и one shot trigger

```cpp
cooldown = (std::max)(0.0f, cooldown - deltaTime);
if (request && cooldown <= 0.0f)
{
    ExecuteAction();
    cooldown = cooldownDuration;
}
```

**Применение:** выстрел, смена укрытия, повторный звук, пересчёт пути.

**Ловушка:** ставить cooldown каждый кадр, пока запрос активен. Тогда он никогда не достигнет нуля.

## 13 Конечный автомат

Минимальная модель:

```text
Idle -> Searching -> Chasing -> TakingCover -> InCover -> Attacking
```

Для каждого состояния зафиксируй:

- условия входа;
- действия во время состояния;
- условия выхода;
- обязательные компоненты;
- восстановительное состояние при ошибке.

**Сложность:** O(1) на сущность за кадр, если состояние исполняет ограниченную работу.

**Ловушка:** менять состояние в нескольких системах без единого владельца перехода.

## 14 Utility scoring

Каждое действие получает нормализованный score.

$$
score=w_1f_1+w_2f_2+...+w_nf_n
$$

Пример выбора укрытия:

```text
score = protection * 5
      + rangeFit * 2
      + peekQuality * 3
      - pathCost * 0.2
      - exposureDuringMove * 4
```

**Порядок:** сначала жёсткие фильтры, затем score. Нельзя компенсировать отсутствующую защиту красивой дистанцией.

**Ловушка:** факторы разных масштабов. Приводи их примерно к 0..1 или явно учитывай диапазоны весов.

## 15 Гистерезис

Гистерезис не даёт переключаться между почти равными решениями.

```cpp
if (newScore > currentScore + switchMargin)
    SelectNewCandidate();
```

Можно добавить минимальное время фиксации решения.

**Применение:** стиль боя, выбор укрытия, оружия, цели.

**Ловушка:** лечить гистерезисом плохие входные данные. Сначала проверь score и геометрию.

## 16 A star

A star ищет путь по графу.

$$
f(n)=g(n)+h(n)
$$

`g` — уже пройденная стоимость, `h` — оценка оставшегося пути.

**Структуры:** open set, closed set, `cameFrom`, стоимость `g`.

**Сложность:** зависит от графа и очереди; с приоритетной очередью обычно близка к O(E log V).

**Применение:** NavMesh или сетка.

**Ловушки:**

- пересчитывать полный путь каждый кадр;
- считать точку достижимой только потому, что она близко геометрически;
- не инвалидировать путь при смене `moveTarget`;
- не различать `NoPath`, `Blocked`, `Arrived`.

## 17 Arrival steering

Обычный seek летит к цели на полной скорости и перелетает её. Arrival снижает скорость рядом с целью.

```cpp
const float distance = Length(toTarget);
const float desiredSpeed = maxSpeed *
    (std::min)(1.0f, distance / slowRadius);
const Vec3 desiredVelocity = Normalize(toTarget) * desiredSpeed;
```

**Применение:** остановка у укрытия и точки ремонта.

**Ловушка:** `slowRadius` меньше `arrivalDistance` или равен нулю.

## 18 Separation

Для каждого близкого соседа создаётся отталкивание, обычно сильнее на малой дистанции.

```text
separation += away / max(distanceSquared, epsilon)
```

**Применение:** NPC не слипаются на пути.

**Ловушка:** запускать полный O(n²) перебор для тысяч сущностей. Используй spatial hash или соседей навигации.

## 19 Spatial hash

Мир делится на ячейки. Координата превращается в целочисленный ключ:

```cpp
cellX = floor(position.x / cellSize);
cellZ = floor(position.z / cellSize);
```

Для поиска в радиусе проверяются соседние ячейки, а не все сущности мира.

**Средняя сложность:** близка к O(1 + k), где k — число локальных кандидатов, при удачном размере ячейки.

**Применение:** восприятие, separation, поиск ближайших объектов.

## 20 Случайное направление внутри конуса

Равномерный разброс по площади нельзя получать равномерным углом по двум осям: это искажает плотность.

Практическая схема:

1. две независимые выборки `u` и `v` от 0 до 1;
2. радиальная часть использует `sqrt(u)`;
3. угол равен `2*pi*v`;
4. строится локальное отклонение;
5. оно переносится в базис `right`, `up`, `forward`.

**Применение:** `WeaponFiringRules::ConeDirection`.

**Ловушка:** делать новую случайную выборку отдельно для дебаг-луча и урона. Один выстрел должен иметь одно фактическое направление.

## 21 Семплирование динамических укрытий

Если авторские точки не покрывают все варианты боя, кандидаты могут генерироваться вокруг NPC или препятствий.

### Кольцо вокруг NPC

```cpp
for (int i = 0; i < sampleCount; ++i)
{
    const float angle = twoPi * i / sampleCount;
    candidate.x = npc.x + std::cos(angle) * radius;
    candidate.z = npc.z + std::sin(angle) * radius;
}
```

Для каждого кандидата:

1. спроецировать на NavMesh;
2. проверить достижимость;
3. проверить защиту несколькими лучами;
4. найти левый и правый peek;
5. оценить расстояние до угрозы;
6. оценить открытость пути;
7. применить score и hysteresis.

**Ловушка:** считать точку укрытием только потому, что один низкий луч встретил стену.

## 22 Профиль укрытия вместо bool

Полезная структура результата:

```cpp
struct CoverProfile
{
    bool standingProtected = false;
    bool crouchingProtected = false;
    bool leftPeekValid = false;
    bool rightPeekValid = false;
    float pathCost = 0.0f;
    float exposureCost = 0.0f;
    float score = -FLT_MAX;
};
```

Так решение не теряет информацию. Анимационный модуль позднее выберет стойку и сторону выглядывания, не повторяя геометрический поиск.

## 23 Reservoir sampling для случайного кандидата

Если кандидатов много и надо равновероятно выбрать один без массива:

```cpp
int seen = 0;
Entity selected = INVALID_ENTITY;
for (Entity candidate : candidates)
{
    ++seen;
    if (RandomInt(1, seen) == 1)
        selected = candidate;
}
```

**Применение:** разнообразие патрульных точек или равных укрытий.

## 24 Ring buffer журнала решений

Храни последние N событий в кольцевом буфере, а не одну быстро меняющуюся строку.

```text
timestamp | state before | decision | reason | state after
```

**Сложность:** O(1) на запись, фиксированная память.

**Применение:** NPC Logic Studio. Это решает проблему мелькающих статусов, которые невозможно прочесть даже в пошаговом режиме.

## 25 Приоритетная очередь событий угрозы

События можно оценивать по важности и свежести:

```text
priority = damageWeight * damage
         + proximityWeight * proximity
         + recencyWeight * freshness
```

Тихое убийство может не создавать общую тревогу, но локальное событие попадания всё равно разворачивает выжившего NPC к близкой угрозе.

**Ловушка:** передавать точную текущую позицию врага через событие навсегда. Получатель должен подтвердить контакт собственным зрением.
