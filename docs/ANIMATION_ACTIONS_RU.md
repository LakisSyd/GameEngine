# Действия рукопашного боя в Animation Studio

Профиль игрока находится в `assets/config/animations/Kevin.json`. При загрузке
старых сцен движок автоматически применяет его к объекту с `PlayerGameTag`.
После сохранения сцены ссылка записывается в поле `animation_profile`.

Сейчас поддерживаются два типа действий:

| Тип в JSON | Ввод | Результат |
| --- | --- | --- |
| `hold_guard` | удержание ПКМ (`Aim`) без оружия | стойка `Kevin_Melee_Guard` |
| `weighted_punch` | нажатие ЛКМ (`PrimaryMouse`) без оружия | случайный удар из `punch_variants` |

## Быстрая правка контроллеров

Во вкладке **Controls** сначала выберите вид **Third Person (3P)** или
**First Person (1P)**, затем нужный клип. Найдите кость в дереве слева и
поставьте playhead на момент, который требуется исправить. Переключатель
**Move / Rotate** выбирает режим gizmo во viewport. Перетаскивание gizmo или
изменение координат в **Details** автоматически создаёт ключ на текущем
времени (**auto-key**).

Кнопки **Add Key** и **Delete Key** добавляют и удаляют ключ в позиции
playhead. **Copy / Paste** переносит поправку положения и вращения, а
**Reset this control for this clip** очищает поправки выбранного контроллера
в текущем клипе.

В группе **Fingers** находятся виртуальные контроллеры **Fist Left** и
**Fist Right**, соответствующие `CTRL_Fist.L` и `CTRL_Fist.R` из исходного
Blender-файла. Слайдер **Fist** управляет всеми фалангами выбранной руки:
`1` добавляет полное сжатие, `0` оставляет позу импортированного клипа,
`-1` раскрывает кисть на ту же величину. Кнопки **Open / Imported / Close**
задают эти значения сразу. Значение записывается ключом на playhead и плавно
интерполируется между ключами. У контроллера кулака собственная фиолетовая
дорожка; его ключи также разделены по клипам и режимам 1P/3P.
Для больших пальцев используется снятая из Blender многоточечная кривая
`Transform / Map From / Map To`: она сохраняет смешанное вращение по трём
осям, влияние constraint и его ограничение входного угла.

После правки нажмите **Save Animation** в верхней панели.

Ключи режима **1P** хранятся отдельно и привязаны к имени выбранного клипа:
изменение контроллера, например в клипе удара, не затрагивает `Idle`, стойку
или другой клип от первого лица. Ключи **3P** сохраняются независимо от 1P.

Параметр `requires_guard` требует удерживать ПКМ во время удара. У каждого
варианта есть отдельные клипы для модели мира и рук от первого лица, рука
удара, момент контакта и `weight`. Шанс равен весу варианта, делённому на сумму
положительных весов. Вес 0 выключает вариант. Если клип модели мира не найден,
вариант пропускается; оружие всегда использует прежнюю систему стрельбы.

В Animation Studio откройте вкладку **Combat**: там доступны клипы стойки,
а также клипы передвижения в стойке для 1P и 3P. Сейчас для обоих видов
назначен `Kevin_Melee_Guard_Walk`: короткие шаги в боевой стойке с движением
обоих кулаков. Если очистить поле, движение использует обычную ходьбу с
руками в стойке.
Далее доступны
требование удерживать ПКМ, добавление вариантов ударов и их веса. Кнопка
**Save Animation** сохраняет профиль. Кнопка **Reload** применяет его сразу в
редакторе. Для сохранения ссылки на профиль вместе со сценой сохраните сцену
обычным способом.

Положение всей модели рук от первого лица можно задавать отдельно для каждого
клипа. Во вкладке **Preview** выберите клип и настройте **Position for
selected 1P clip**. Во вкладке **Combat** есть отдельные поля **1P guard
position** и **1P position for this attack** для выбранного варианта. Эти
поправки сохраняются в `first_person_clip_offsets` профиля анимаций. Обычный
`Idle` использует базовую позицию рук и не меняется от настроек стойки или
удара. Поле **Shared base arms position (all clips)** меняет все анимации,
включая `Idle`.

Скорость каждого клипа настраивается в **Preview** через **Selected
clip speed**. Для стойки, ходьбы в стойке и выбранного удара те же настройки
показаны во вкладке **Combat**. `1.0x` означает исходную скорость; допустимый
диапазон — от `0.1x` до `5.0x`. Значения сохраняются в `clip_speeds` внутри
`Kevin.json`. Удары от первого лица следуют времени соответствующего удара
от третьего лица, поэтому момент попадания остаётся согласованным.

Формат `actions` оставляет место для следующих типов действий. Исполнитель
пока поддерживает только `hold_guard` и `weighted_punch`; неизвестные типы
игнорируются.
