# Runtime Mesh Cutting Guide

Этот файл описывает текущий тест резки меша в движке.

## Где код

- `src/ECS/System/MeshCuttingTest.h`
- `src/ECS/System/MeshCuttingTest.cpp`
- `src/Render/Model/assimpmodelclass.h`

Тест запускается на `F6`.

## Как работает F6

1. `ApplicationClass` строит ray через `CameraClass::CreatePickingRay`.
2. `MeshCuttingTest::CutByRay` перебирает все активные `MeshRendererComponent`.
3. Луч переводится из world space в local space каждого объекта.
4. Код ищет ближайший треугольник через `DirectX::TriangleTests::Intersects`.
5. В точке попадания берется:
   - local hit position;
   - local surface normal;
   - radius будущей дырки.
6. `AssimpModelClass::CutCircularHoleForTest` режет CPU-копию меша.
7. Создаются новые DirectX vertex/index buffers.
8. Если у entity есть `RigidBodyComponent`, физический коллайдер пересоздается.

## Главная идея clipping

Раньше тест делал грубо:

```text
если треугольник попал в радиус
    удалить весь треугольник
```

Теперь логика мягче:

```text
треугольник -> временный polygon
круглая дырка -> 24-гранный convex polygon
из треугольника вычитается этот polygon
остатки снова превращаются в треугольники
```

То есть большой треугольник может стать несколькими маленькими треугольниками вокруг края дырки.

## Почему дырка не идеальная

Это еще не полноценный CSG:

- край дырки не закрывается боковыми полигонами;
- нет отдельного материала для обгоревшей кромки;
- круг приближен 24 сторонами;
- если меш очень редкий, результат все равно может быть грубым.

Но это уже настоящий шаг после удаления целых треугольников.

## Простая схема

```text
ray hit
   |
   v
local hit point + local normal
   |
   v
строим плоскость удара
   |
   v
строим 2D круг на этой плоскости
   |
   v
каждый треугольник рядом с плоскостью:
    вычесть круг
    остатки триангулировать
   |
   v
rebuild GPU buffers
   |
   v
rebuild Bullet rigid body
```

## Почему отдельно режется collision mesh

У корабля могут быть два разных слоя:

- видимый mesh, например стенка/корпус, который рисуется;
- физический mesh, например `SHIP_COL_*`, который не рисуется, но по нему ходит игрок.

Если вырезать дырку только в видимом mesh, картинка изменится, но Bullet всё равно будет держать игрока старой невидимой стеной. Поэтому `CutByRay` теперь делает два поиска:

1. ближайшее попадание в `MeshRendererComponent` - для визуальной дырки;
2. ближайшее попадание в `RigidBodyComponent` / `collisionModel` - для физической дырки.

После изменения физического меша вызывается `PhysicsSystem::RefreshRigidBody`, и `btBvhTriangleMeshShape` строится заново уже из изменённых треугольников.

## Что изучать в коде первым

1. `CutByRay` - как луч находит треугольник.
2. `CutCircularHoleForTest` - как весь меш прогоняется через резку.
3. `SubtractConvexDiskFromTriangle` - самое важное место: вычитание дырки из одного треугольника.
4. `ClipPolygonByEdge` - базовый clipping polygon по одной линии.
