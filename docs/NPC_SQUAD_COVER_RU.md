# Отрядный бой NPC и укрытия

## Как запустить полигон

Открой `CombatTrainingGround.json` через **File → Load Scene**, затем включи Play Mode.
Для прямого запуска движка можно передать аргумент `--combat-arena`.

## Из чего состоит система

- `NpcCoverPointComponent` — дизайнерская точка за физическим препятствием.
- `NpcTacticalComponent` — настройки бойца, номер отряда и текущая роль.
- `NpcSquadCombatSystem` — обмен последним визуальным контактом, выбор ролей,
  оценка и резервирование укрытий, переключение скрытой и открытой фаз.
- `StateSystem` — только исполняет назначенное движение. Это сохраняет одного
  владельца `CharacterMovement` и не создаёт борьбу разных систем за capsule.

Один боец с минимальным Entity ID в отряде получает роль `Suppressor`.
Остальные получают роль `Flanker` и сильнее предпочитают боковые позиции.
Укрытие обязательно проверяется физическим лучом: маркер сам по себе не делает
NPC неуязвимым, если между точкой и игроком нет статического препятствия.

## Как добавить новое укрытие

1. Создай обычный объект-маркер с `TransformComponent`.
2. Добавь ему **NPC Cover Point**.
3. Поставь Transform за статическим коллайдером.
4. Настрой `Peek local offset`, чтобы смещённая точка выглядывания видела игрока.
5. Если нужна стойка, выключи `Crouched pose`.

Маркер не обязан иметь MeshRenderer. Положение за укрытием и точка выглядывания
могут находиться с разных сторон препятствия; благодаря этому тем же компонентом
можно сделать левый/правый выход, угол стены или низкий ящик.

## Анимации, которые можно добавить позже

Присевший NPC уже выбирает `AnimationState::CrouchRifleIdle`. Пока binding пуст,
остаётся обычная оружейная поза. После добавления клипа достаточно назначить его
в Animation Studio. Для красивого lean/peek можно позже добавить отдельные
состояния, читая `NpcTacticalComponent::exposed` и `movingToPeek`; сама тактика
и резервирование укрытий при этом не меняются.

## Основные настройки NPC

- `Squad ID` — бойцы с одинаковым номером делятся контактом и ролями.
- `Hide duration` — время за укрытием.
- `Expose duration` — окно стрельбы из точки выглядывания.
- `Preferred range` — желаемая дистанция выбранного укрытия от игрока.
- `Flank weight` — насколько сильно фланкер предпочитает боковую позицию.
- `Decision interval` — частота дорогого пересчёта доступных точек.

Состояние, роль и зарезервированная Entity отображаются в инспекторе во время Play.
