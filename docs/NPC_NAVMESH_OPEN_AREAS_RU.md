# NavMesh на открытой локации

`RoomComponent` нужен для отсеков корабля, но не нужен для открытой площадки. Для такой сцены NavMesh строится из статических коллайдеров с компонентом `NavMesh Surface`.

## Как настроить пол

1. Выдели объект пола в редакторе. На нём должен быть `Rigid Body` с `Mass = 0` и коллизией `Box`, `TriangleMesh` либо другой конечной формы. Для большого ровного пола удобна тонкая коробка. Бесконечный `Plane` для NavMesh не подходит.
2. В инспекторе нажми `+ Add Component` → `NavMesh Surface`. Проверь, что `Walkable collision surface` включён.
3. Так же пометь другие участки земли, по которым NPC должен ходить. Стены, ящики и прочие препятствия оставь без `NavMesh Surface`: их статические коллайдеры вырезают место из проходимой области.
4. Сохрани сцену и запусти Play. У NPC вне `RoomComponent` команда перемещения и Wander используют общий NavMesh сцены. В отладке NPC включи `Draw NavMesh in world`: голубые линии покажут проходимые полигоны, жёлтые — найденный путь.

Например, для двора можно пометить коллайдеры `Ground_A`, `Ground_B` и `Ramp` одним и тем же компонентом. Никаких объектов с `RoomComponent` вокруг двора создавать не надо. Поверхности должны физически соприкасаться с учётом радиуса NPC и шага подъёма, иначе Recast получит отдельные острова.

## Что осталось корабельным

Внутри корабельной комнаты навигация по прежнему строится из `SHIP_PANEL` и лестниц; отмеченные `NavMesh Surface` коллайдеры тоже принимаются. Переходы между комнатами по прежнему задаются дверями. Снаружи комнаты используется NavMesh отмеченных поверхностей.

## Ограничение размера

Сейчас открытая сцена запекается в один NavMesh. Если общая область отмеченных поверхностей потребует больше 4 млн ячеек Recast при шаге 0,2 м, в статусе NPC появится сообщение о пределе размера. Для очень больших миров следующим этапом понадобится плиточный NavMesh со стримингом, а не одна огромная высотная карта.
